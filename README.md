# 용인강남학교 진로·진학정보

졸업 후 우리 아이가 갈 수 있는 곳(진학·취업·교육 및 훈련기관·지역사회 유관시설·복지서비스)을 안내하는 웹앱입니다.

- 제작·발행: 용인강남학교 진로직업부
- 휴대폰에서 열고 "홈 화면에 추가" 또는 "앱 설치"를 누르면 앱처럼 쓸 수 있습니다.

## 내용 고치기
- 기관·문구는 `index.html` 안의 `/* 내용 */` 부분에서 고칩니다.
- 지도 점 위치는 `mapdata.js`, 전국 훈련센터는 `krmap.js`에 있습니다.
- 고친 뒤에는 `sw.js`의 `VERSION` 값을 바꿔 주세요(예: v1 → v2). 그래야 휴대폰에 저장된 옛 화면이 새것으로 바뀝니다.
